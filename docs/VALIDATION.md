## 设备与环境边界

本轮 HDC 未发现设备，1.0.0 尚未完成真机验收。未签名 HAP、SDK 原生渲染和真机安装是不同的验证阶段。

SDK 的系统 API 和 Preferences 是模拟实现，预览器退出时仍有原生崩溃记录。扫码、文件选择／上传／下载、相机／相册、新电脑偏好持久化、长锁屏和切网仍需在具体设备上验收。SDK 截图不能替代这些测试。

未对在用 DSH 实例主动执行重启、生产配置修改或授权撤销。浏览器独立视觉复验未在本轮完成；网络探测和源码检查不等同于浏览器交互验收。
