# DSH Connect 1.0.11 验证记录

验证日期：2026-11-06。维护源、本机插件和 Mate 80 安装版本为 1.0.11／10011。

## 构建与回归

- 版本同步、JavaScript 语法、设置图标同步检查与 74 项隔离回归通过。检查覆盖原有文件夹按钮的手机点击与宽屏行为、手机附件入口、当前工作区文件浏览，以及隐藏侧栏不应吞掉返回操作。
- 官方 API 26 工具链构建公开 release HAP：com.lumiao.dshconnect、debug=false、未签名。设备包沿用原应用身份与私有签名。
- Cn 的 13 项派生资源检查通过；图标始终固定黑底白字。
- 本机插件的 35 个安装文件与正式 TGZ、维护源逐字节一致。采用固定版本包，经 DSH 原生插件接口加载。

## 原生界面

Mate 80 验收使用 1280 × 2832 完整系统截图。电脑卡片右上角为独立的竖排三点，点按打开系统菜单；卡片按压与左右切换由 ArkUI 驱动。点按卡片可回到已连接工作区。

设置、帮助、添加电脑、重命名与移除确认从底部打开系统半模态面板。设置保留两个系统开关。设置面板顶部位于距屏幕顶部约三分之一处，帮助和编辑表单留出更多首页背景。从设置进入添加电脑，系统返回后重新显示设置；从电脑卡片滑到添加页也能打开同一个面板。移除确认已打开并取消。

添加电脑提供扫码和网址输入。真机打开 URL 键盘时，首页上方仍可见，输入框与连接按钮均在键盘上方。检查中没有提交链接。

公开图册来自 SDK 原生渲染与演示电脑数据，包含两种首页状态、电脑菜单、添加电脑、设置和帮助。真实设备截图与签名材料仅保存在本地。

## 工作区与连接

Mate 80 覆盖安装后，UID、首次安装时间、签名和原电脑授权保持一致。冷启动进入现有 HTTPS 工作区，连接状态为 connected。当前设备无需代理／VPN。Focus、Suggestions 与其他项目保持原安装。

1.0.10 的工作区版式回归记录保留。手机对话保留 DSH 自带的文件夹按钮及其图标、边框、尺寸和槽位。实际触控打开 DSH 文件面板，宽 366 CSS px，与手机视口等宽，随后返回可退出文件浏览。点按前后电脑文件资源管理器的窗口状态一致。

手机「＋」直接调用既有附件输入，弹出原生拍照、相册、浏览文件面板。系统文档选择器曾在 1.0.9 打开并取消。

顶部导航高 40 px、品牌字号 12 px；对话标题和页签区约 66.29 px。1.0.10 通过文字 Range 实测，对话标题与首个页签的首字均从左侧 12 CSS px 开始；标题首字原有的 8 px 内缩已校正。页签字号 12 px，输入工具行宽约 340.29 px。

页面背景继续使用 ArkUI 原生安全区与 ArkWeb 底部扩展绘制。系统手势区无独立白色背景带；网页操作区保留系统提供的 29 CSS px 避让。侧栏内容与外层宽度一致。
