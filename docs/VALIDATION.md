## 1.0.17 本机验证

2026-11-07，源码检查及 95 项回归通过。同网入口覆盖 HTTPS 配对、证书指纹、一次性令牌、授权撤销和监听器切换。内置中继在隔离环境覆盖 HTTPS 请求、上传、WebSocket、授权拒绝和服务重连。

电脑插件覆盖安装后，37 个包内文件逐项校验一致。Mate 80 覆盖安装 1.0.17／10017，应用 UID 保持 20020219，原授权恢复到真实工作区，传输状态为 connected。

Mate 80 经调试转发测试同网链路。错误证书指纹未产生授权，正确指纹完成配对与 WebSocket 收发，应用重开后恢复；撤销后 WebSocket 关闭、请求返回 401。测试电脑卡片已移除。实际路由器局域网和蜂窝跨网尚待验证，当前没有已部署的默认公网中继。

本机证据位于 `_wip/AUTO_20261107BuiltinConnection`。签名 HAP 用于指定设备，公开安装包仍按 Release 标注。

## 原生界面

Mate 80 验收使用 1280 × 2832 完整系统截图。电脑卡片右上角为独立的竖排三点，点按打开系统菜单；卡片按压与左右切换由 ArkUI 驱动。点按卡片可回到已连接工作区。

设置、帮助、添加电脑、重命名与移除确认从底部打开系统半模态面板。1.0.11 真机核对了设置开关、设置与添加电脑间的返回、卡片滑动和移除确认取消。1.0.12 中，短面板按内容定高，底部按系统手势区留出间距，长内容可以滚动。

添加电脑提供扫码和网址输入。真机打开 URL 键盘时，首页上方仍可见，输入框与连接按钮均在键盘上方。检查中没有提交链接。

公开图册来自 SDK 原生渲染与演示电脑数据，包含两种首页状态、电脑菜单、添加电脑、设置、帮助和附件面板。真实设备截图与签名材料仅保存在本地。

## 工作区与连接

Mate 80 覆盖安装后，UID、首次安装时间、签名和原电脑授权保持一致。冷启动进入现有 HTTPS 工作区，连接状态为 connected。当前设备无需代理／VPN。Focus、Suggestions 与其他项目保持原安装。

1.0.14 在 Mate 80 使用 Harness 原有会话标题栏、侧栏按钮和抽屉遮罩。点按侧栏按钮打开抽屉，点按遮罩关闭。对话、轨迹、上下文和编队使用 Harness 原有的 32 CSS px 页签间距，同排显示。四项均已实际点按切换。页签右侧的更多按钮打开 Harness 插件菜单。

文件夹左侧的团队图标完整显示，点按打开 Harness 团队面板。在 Mate 80 上加入较宽的测试内容后，会话状态区可单独横滑，标题、文件夹、更多和两侧侧栏按钮位置固定。

状态行位于输入框外，行顶留 2 CSS px。Mate 80 状态行底部到屏幕底边为 29 CSS px，与系统手势避让一致。键盘弹出时，状态行距键盘约 6 CSS px，键盘收起后恢复系统留白。轨迹搜索框左右各留 12 CSS px。

1.0.10 的工作区版式回归记录保留。手机对话保留 DSH 自带的文件夹按钮及其图标、边框、尺寸和槽位。实际触控打开 DSH 文件面板，宽 366 CSS px，与手机视口等宽，随后返回可退出文件浏览。点按前后电脑文件资源管理器的窗口状态一致。

手机「＋」直接调用既有附件输入。Mate 80 核对了紧凑的原生附件面板、三项入口和手势条上方的间距，弹出前后网页高度一致。系统文档选择器曾在 1.0.9 打开并取消。

左侧原生按钮及页签共用 12 CSS px 页面边距，会话标题排在按钮右侧。页签字号 12 px，工作区实际宽 366 CSS px。

页面背景继续使用 ArkUI 原生安全区与 ArkWeb 底部扩展绘制。系统手势区无独立白色背景带；网页操作区保留系统提供的 29 CSS px 避让。侧栏内容与外层宽度一致。
