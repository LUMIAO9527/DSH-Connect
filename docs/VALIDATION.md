## 原生界面

完整 1280 × 2832 的 Mate 80 截图核对：首页使用接近方形的紧凑电脑卡片；添加卡片尺寸相同，滑动可达；底部使用帮助为带箭头的跳转按钮。设置页返回键具有圆角边框，与内容左边距一致；恢复行为、电脑和版本更新使用分组条目。

点按添加卡片打开原生底部面板，提供扫码和网址输入。网址输入使用系统 URL 键盘及 Go 提交操作。根据系统键盘可见状态切换原生面板高度档位，配合原生滚动与键盘避让；真机键盘打开时输入框和连接按钮均可见，收起后恢复半屏。检查中没有输入或提交链接。

公开图册来自 SDK 原生渲染与演示电脑数据。首次使用、已保存电脑、添加面板和设置分别核对；真实设备截图与签名材料仅保存在本地。

## 工作区与连接

Mate 80 覆盖安装后，UID、首次安装时间、签名和原电脑授权保持一致。冷启动进入现有 HTTPS 工作区，连接状态为 connected。当前设备无需代理／VPN。Focus、Suggestions 与其他项目保持原安装。

手机文件夹入口通过 DSH 的公开文件面板接口浏览当前电脑目录。真机面板宽 366 CSS px、高约 731.14 px，桌面应用启动按钮不在手机显示。返回操作可退出文件浏览；不可见的导航对话框不会拦截返回。

手机“＋”直接调用既有附件输入；真机打开原生拍照／相册／文件选择面板前后网页高度均为 771 px，没有拉起键盘。系统文档选择器已实际打开并取消，未选择、上传或发送私人文件。

顶部导航高 40 px、品牌字号 12 px；对话标题和页签区约 66.29 px，标题与页签内容从左侧 12 px 开始，页签字号 12 px。输入工具行宽约 340.29 px，保留完整横向空间。

页面背景继续使用 ArkUI 原生安全区与 ArkWeb 底部扩展绘制。系统手势区无独立白色背景带；网页操作区保留系统提供的 29 CSS px 避让。侧栏内容与外层宽度一致。
