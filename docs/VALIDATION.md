## 本机与 Mate 80

电脑插件运行版本为 1.0.6，正式 TGZ 的 35 个文件与安装目录逐字节一致。依赖来源指向 artifacts 内的固定版本包；通过官方插件管理接口重新加载。Focus 与 Suggestions 保持原安装。

Mate 80 覆盖安装 1.0.6／10006，UID、首次安装时间和签名回读一致。原电脑列表与授权保留；冷启动进入真实 DSH 工作区，实时状态为 connected。首页返回工作区可继续使用原页面。

在完整 1280 × 2832 设备截图中，首页、设置、工作区侧栏背景均延伸至系统手势条下方，底部白带消失。工作区使用 ArkUI 原生安全区与 ArkWeb expandSafeArea；系统提供的底部 env 值为 29 CSS px，输入区保留 29 px 避让，侧栏底部保留 35 px。侧栏外层与内容宽度均为 311.10 px，原有白边消失。

键盘弹出时，网页视口从 771 px 缩至 457 px，底部避让变为 0；关闭后恢复 771 px 与 29 px。整个检查没有输入或发送内容。网页浅深配色下的完整设备截图均已检查；深色检查使用临时媒体配色模拟，随后恢复。

当前 Mate 80 已在不使用代理／VPN 的条件下连接现有 HTTPS 入口。早期受限环境中的公网超时不足以证明手机公网通道不可用；后续实际主机 HTTPS 返回 200，手机进入真实工作区。不能继续沿用“公网不可达”的旧结论。

对话标题清除桌面版 28 px 左侧占位，实际起点从 48 px 调整为 12 px。移动导航高 44 px、对话标题和页签区约 64.29 px，上方整体由 130 px 压缩到约 108.29 px。对话标题、文件与工具按钮保持可用。
