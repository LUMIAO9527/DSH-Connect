# 首次使用、更新与卸载

## 选择文件

| 文件 | 用途 |
| --- | --- |
| `dsh-connect-版本.tgz` | 在电脑的 DSH 插件管理中安装 |
| `DSH-Connect-版本-source.zip` | 完整源码、构建脚本和说明 |
| `DSH-Connect-版本-icon.svg` | 插件图标 |
| `SHA256SUMS.txt` | 文件校验和 |

手机不需要安装任何应用，用浏览器打开电脑给出的链接即可。

## 第一次使用

电脑插件的设置页提供配对链接和二维码。手机扫码、直接打开链接，或把链接粘贴到配对页输入框即可完成配对；也可以手动输入 43 位配对码。局域网内手机扫码直连；跨网使用已接通的 HTTPS 入口。配对后浏览器记住这台电脑，之后用永久链接打开即可恢复。

同一台电脑可以配多个浏览器，各自保存授权。

## 更新

在「设置 → DSH Connect → 版本更新」检查并安装。插件校验安装包后交给 DSH 插件管理器安装，失败会恢复上一版；固定地址、端口和设备状态保持不变。

## 卸载

手机浏览器：撤销这台电脑的授权，或清除该站点的数据。

电脑插件：先在设置页撤销设备授权，再在插件管理中停用并移除；设备状态文件按需保留或删除。
