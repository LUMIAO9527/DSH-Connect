# 首次使用、更新与卸载

## 选择文件

| 文件 | 用途 |
| --- | --- |
| `dsh-connect-版本.tgz` | 在电脑的 DSH 插件管理中安装 |
| `DSH-Connect-版本-source.zip` | 完整源码、构建脚本和说明 |
| `DSH-Connect-版本-icon.svg` | 插件图标 |
| `SHA256SUMS.txt` | 文件校验和 |

手机不需要安装任何应用，用浏览器打开电脑给出的链接即可。

## 第一次使用

电脑插件的设置页提供配对链接和二维码。私有局域网内手机扫码直连；跨网使用已接通的 HTTPS 入口。配对后浏览器记住这台电脑，之后用永久链接打开即可恢复。

同一台电脑可以配多个浏览器，它们各自保存授权；撤销其中一个不影响其他。

## 更新

电脑插件在「设置 → DSH Connect → 版本更新」检查并安装更新。下载限定本项目的正式插件包，核对大小、SHA-256、包名与版本后交由 DSH 原生插件管理器安装；安装失败会尝试恢复上一版。更新保留固定入口、端口和状态目录。

插件沿用既有设备状态目录；历史默认目录存在时原地复用，自定义目录继续使用原配置。不要同时启用两个占用同一端口的连接器。

自定义状态目录必须是持久路径，默认是 `~/.dsh/dsh-connect`。不要指向 `_wip`、缓存或其他会被清理的临时目录：目录不存在时插件会按新安装生成空设备状态，原有授权需要重新配对。

## 卸载

手机浏览器：撤销这台电脑的授权，或在浏览器中清除该站点的数据。两者都会让这个浏览器需要重新配对。

电脑插件：先在 DSH Connect 设置页撤销设备授权，再到 DSH 插件管理中停用并移除插件。插件的设备授权状态可能作为独立文件保留。需要彻底移除时，先确认插件已经停用、备份仍需保留的授权，再仅删除配置指定的连接器状态目录。不可删除 DSH 的工作区、会话、用户资料或整个 DSH 数据目录。

## 源码与本机材料

源码：`desktop-plugin`、`branding`、`tools`。正式安装产物在 `artifacts`，构建、缓存、预览和验证记录在 `_wip`。

构建入口为 `Build-Release.ps1`；它校验版本一致、插件回归和源码 ZIP 的逐项内容。构建成功不等于真机验收，手机上的实际连接仍需单独验证。
