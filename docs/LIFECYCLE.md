# 首次使用、更新与卸载

## 选择文件

| 文件 | 用途 |
| --- | --- |
| `DSH-Connect-版本-unsigned.hap` | 鸿蒙应用的 release 构建；配置自己的开发签名后安装 |
| `dsh-connect-版本.tgz` | 在电脑的 DSH 插件管理中安装 |
| `DSH-Connect-版本-source.zip` | 完整源码、构建脚本和说明 |
| `DSH-Connect-版本-preview.html` | 使用演示数据的界面图册 |

手机应用和电脑插件分别安装，各自保存连接所需的数据；完整 DSH 工作区、会话、文件和工具仍由电脑上的 DSH 管理。

## 第一次使用

1. 在电脑打开 DeepSeek Harness，安装并启用 DSH Connect 插件。
2. 配置固定 HTTPS 入口，将 HTTP 与 WebSocket 转发到插件本机网关；在“设置 → DSH Connect”填写电脑访问地址并点击“启用连接”。
3. 打开“设置 → DSH Connect”，生成配对二维码或链接。
4. 手机应用在“添加电脑”中扫描二维码或粘贴完整链接；浏览器直接打开链接。应用和各浏览器分别完成一次配对。
5. 保存电脑连接。以后从首页打开，或开启自动恢复工作页面。

## 更新

手机应用“设置 → 版本更新”可检查正式版本并打开发布页。覆盖更新必须保持应用标识与签名一致；自签名安装需要由原签名方签装，不能直接把未签名 HAP 当作通用安装包。正常覆盖更新保留手机上的电脑列表和登录状态。开发预览包与公开包使用的应用标识可能不同，不能把卸载重装当作保留数据的升级。

电脑插件在“设置 → DSH Connect → 版本更新”检查并安装更新。下载限定本项目的正式插件包，核对大小、SHA-256、包名与版本后交由 DSH 原生插件管理器安装；安装失败会尝试恢复上一版。更新保留固定入口、端口和状态目录。开发目录显示源码维护状态，继续通过源码构建更新。

插件沿用既有设备状态目录；历史默认目录存在时原地复用，自定义目录继续使用原配置。不要同时启用两个占用同一端口的连接器。

## 卸载

手机：在桌面长按 DSH Connect 图标，选择卸载。应用保存的电脑连接、偏好和登录状态随应用数据移除；电脑上的 DSH 数据不受此操作影响。

电脑插件：先在 DSH Connect 设置页撤销设备授权，再到 DSH 插件管理中停用并移除插件。插件的设备授权状态可能作为独立文件保留。需要彻底移除时，先确认插件已经停用、备份仍需保留的授权，再仅删除配置指定的连接器状态目录。不可删除 DSH 的工作区、会话、用户资料或整个 DSH 数据目录。

仅从手机首页“移除电脑”会移除该条本机连接；它不会替代电脑端的设备授权撤销。

## 源码与本机材料

源码：`harmony`、`desktop-plugin`、`branding`、`tools`。正式安装产物在 `artifacts`，构建、缓存、预览和验证记录在 `_wip`。官方 SDK 和预览宿主依赖按用途保留；手机调试签名输入只作本机私密输入，不进入源码包、插件包或公开发布附件。

构建入口为 `Build-Release.ps1`；它校验版本一致、电脑插件回归、HAP 内部应用标识和资源，以及源码 ZIP 的逐项内容。手机签装和安装需另行执行，不能以构建成功代替真机安装验证。
